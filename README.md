# Merge Numbers — v3.9

HTML5-игра 2048. Исходники и 13 изображений котиков сверены с архивом `Merge_Numbers_v3.9_Fixed_Cat_Tiles.zip`: все 17 файлов совпадают побайтово.

[Играть](https://pankovs13-glitch.github.io/merge-numbers/)

## Структура

- `index.html` — интерфейс и подключение SDK Яндекс Игр.
- `game.js` — ходы, слияния, анимации, монеты, магазин и сохранение.
- `style.css` — оформление, адаптивная вёрстка и темы.
- `assets/cats/00.png` … `12.png` — 13 изображений плиток.
- `README.txt` — заметки исходного архива.

Сборщик и установка зависимостей не требуются. Для локальной проверки выполните `python3 -m http.server 8000` в корне проекта и откройте `http://localhost:8000`.

## Сохранённые функции

Классический 2048, клавиатура и свайпы, анимации движения и слияний, звук, рекорд, монеты за достижения, магазин тем (Классика, Котики, Ретро-ПК, Фастфуд). Прогресс хранится в localStorage под ключом `merge-numbers-yandex-classic` и привязан к браузеру и адресу сайта.

В исходной v3.9 есть тестовая кнопка `+2000 монет`; она сохранена. Это тестовая сборка.

## Публикация и дальнейшая разработка

GitHub — основной источник проекта. GitHub Pages автоматически публикует `main`; действующая публикация проверена 3 ноября 2026 года.

1. Создать рабочую ветку от актуального `main`.
2. Изменить исходники и изображения непосредственно в репозитории.
3. Проверить игру локально: ходы и счёт, анимации, покупку/выбор тем, монеты и сохранение после перезагрузки.
4. Открыть pull request, проверить изменения и объединить в `main`.
5. Дождаться успешного `pages build and deployment` в Actions и проверить опубликованную игру.

Повторная пересылка ZIP для разработки не требуется. Не менять ключ сохранения без миграции данных.

## Проверка v3.9

В опубликованной игре проверены ходы и слияние (4 + 4 = 8), покупка темы Котики (2000 → 1800 монет), отображение изображений и восстановление счёта, баланса и темы после перезагрузки.

SDK Яндекс Игр вне платформы Яндекса пишет предупреждения и ошибки `No parent to post message`; базовая игра работает. Рекламу и платформенные функции необходимо отдельно проверять в среде Яндекс Игр. Полная мобильная проверка и рекламные сценарии в эту проверку не входят.
