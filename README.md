# Merge Numbers — v4.0 Classic

[Играть](https://pankovs13-glitch.github.io/merge-numbers/)

Классический 2048 без магазина, монет и тем. Числовые плитки, анимации движения и слияний, звук, рекорд, прогресс к 2048, свайпы и экранные кнопки сохранены.

## Структура и запуск

- `index.html` — интерфейс и SDK Яндекс Игр.
- `game.js` — игровая логика и сохранение.
- `style.css` — оформление и анимации.

Сборщик не требуется: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`.

## Переход с v3.9

Магазин, монеты, косметические темы и картинки котиков удалены из текущей версии. Они остаются в истории Git. Текущая партия, очки, рекорд и настройки звука загружаются по прежнему ключу `merge-numbers-yandex-classic`. Старые поля темы и валюты игнорируются; игра всегда отображает числа.

Приложенная классическая v1.6 использована как ориентир; актуальные анимации и исправления адаптивной вёрстки сохранены.

## Работа через GitHub

GitHub — основной источник. Изменения выполняются в рабочей ветке, проверяются и объединяются в `main`. GitHub Pages автоматически публикует `main`; после обновления нужно проверить успешный запуск `pages build and deployment` и саму игру. ZIP для дальнейшей разработки не требуется.

Проверять: ходы, слияния и счёт, анимации, загрузку старого сохранения, перезагрузку, новый раунд, победу и отсутствие ходов. Не менять ключ сохранения без миграции.

SDK Яндекса вне Яндекс Игр может выдавать `No parent to post message`. Рекламу следует проверять на площадке Яндекса.
